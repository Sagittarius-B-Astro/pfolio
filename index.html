Orbital Transfer Calculator

The OTC implements a user-friendly interface to calculate orbital transfers, asking for parameters for the Hohmann, Bi-Elliptic Hohmann, Common Apse Line, Apse Line Rotation, and Plane Change transfers. Upon calculation, it displays the results and visualizes the initial, target and transit trajectories on an embedded Desmos Calculator. Technical documentation attached to the project provides a detailed explanation of the calculations and assumptions made in the code [TBD]

Options Pricing and Greeks Calculator

This streamlit application uses pandas, seaborn, and matplotlib to allow the user to calculate the ideal price for a call and put given various user inputs (Price of Option, Current Asset Price, Strike Price, Time to Maturity, Risk-Free Interest Rate, Volatility, Dividend), and outputs the result as a heatmap of the option price over a range of strike prices and times to maturity. Heston model is yet to be implemented properly [TBD] The Greeks page calculates every Greek for a given option, and the VaR calculator page calculates the Value at Risk for a given portfolio of options.

AquaMetric

This project is an attachment for a Brita 18-cup water dispenser that automatically dispenses a user-specified volume of water. My approach derives theoretical drain-time equations from the Bernoulli and continuity equations for a trapezoidal frustum tank, then fits corrective cubic (volume) and quintic (time) regression models in Python using sklearn to account for real-world measurement error, achieving a final volume error of around 19 mL. The corrected models use the Secant root-finding method to calculate drain time from the sensor's height reading and the user's requested volume. The code and technical writeup are available in the GitHub repository.

Guitar Tabber

This application is designed to take an audio file of a guitar performance and output a tablature representation of the performance. The scope is currently limited to a single acoustic guitar. My approach uses a combination of signal processing and machine learning techniques - note detection with STFTs / CQTs, and timbre analysis + technique identification with specialized neural networks. Currently, standing issues include on improving the onset detection algorithm for the notes, the accuracy of the guitar technique identification, tuning identification, and tablature conversion algorithm. The code is not yet linked in the repo but the readme / technical docs is available for reference [TBD]
